# Bug Diary

Track bugs, root causes, and fixes here throughout the build.

## Bug Template

Use the five headings below for each entry.

---

## Bug ID: BUG-XXXX — Short title

### Symptom
What the system did that was wrong (observable output or failure).

### Root Cause
Why it happened (code path, data issue, model behaviour, etc.).

### Fix
What was changed to resolve it.

### Verification
How the fix was confirmed (test added, command run, eval case passed).

### Lessons Learned
Any generalizable insight for future agents or contributors.
